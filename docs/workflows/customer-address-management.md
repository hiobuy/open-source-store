# Customer Address Management

Under "Customer Management" in the admin console, "Customer Address Management" allows searching shipping addresses by customer name, email, member code, recipient, phone, city, or street, with 25 items per page. Click "View Address Book" to manage all addresses for that customer; for customers without any addresses, open the customer list via "Select Customer" and click "Addresses" on that customer.

Customer support has read-only access, while managers and owners can add, edit, set as default, and delete addresses. The admin console and client share address data and destination validation; address snapshots on already created logistics orders remain unchanged. Writes record the audit action, customer ID, and address ID without logging full shipping details. This entry point is not available in the demo admin console.
